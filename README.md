# GameHub

An intelligent gaming platform featuring 7 classic games with AI-powered opponents and adaptive gameplay mechanics. Built with Streamlit and Python, AI GameHub brings together classic games enhanced with artificial intelligence that adapt to player skill levels, creating a personalized and challenging gaming experience. The platform includes performance tracking, leaderboards, and time-based statistics to monitor your progress.

## ✨ Features

- 🤖 AI-powered opponents with multiple difficulty levels
- 📊 Real-time leaderboard and statistics
- ⏱️ Game timer for performance tracking
- 🎨 Clean and intuitive user interface
- 💾 Session state management
- 🏆 Personal best tracking

## 🎯 Games Included

| Game | AI Features | Highlights |
|------|-------------|------------|
| **Tic Tac Toe** | Minimax Algorithm | 3 difficulty levels, unbeatable Hard mode |
| **N-Queens** | Backtracking | Visualize solutions, interactive play mode |
| **Sudoku** | Backtracking Solver | Auto-generate puzzles, instant solver |
| **Connect 4** | Minimax with Depth Search | Human vs AI, strategic gameplay |
| **2048** | Score Optimization | Classic sliding puzzle, high score tracking |
| **Hangman** | Word Database | Tech-themed words with clues |
| **Maze Runner** | BFS Pathfinding | Procedural generation, auto-solver |

### Installation
```bash
# Clone the repository
git clone https://github.com/yourusername/ai-gamehub.git
cd ai-gamehub

# Install dependencies
pip install -r requirements.txt

# Run the application
streamlit run app.py
```

### Access the App
Open your browser and navigate to `http://localhost:8501`


## 🎮 How to Play

1. **Enter your name** in the sidebar
2. **Select a game** from the dropdown menu
3. **Follow on-screen instructions** for each game
4. **View your stats** in the leaderboard

## 🧠 AI Algorithms

- **Minimax**: Optimal decision-making for Tic Tac Toe and Connect 4
- **Backtracking**: Solution finding for N-Queens and Sudoku
- **BFS**: Shortest path calculation for Maze Runner
- **Adaptive Logic**: Dynamic difficulty adjustment based on performance
